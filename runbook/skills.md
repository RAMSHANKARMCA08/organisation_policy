# Runbook skills

Use the runbook matching the failure domain: EKS/Kubernetes, Docker, Terraform, Jenkins, Azure Pipelines, or application. Collect sanitized evidence, follow deterministic validation, and require human approval for production-impacting actions.




Security toolchain: Gitleaks scans secrets and Checkov scans infrastructure-as-code. Both use pinned CI versions, normalized findings, and the shared exception/release-gate process.
